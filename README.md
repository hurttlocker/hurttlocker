# Marquise Hurtt

I build the layer underneath AI coding agents: the control room that decides what they may touch, and the memory they come back to.

**[o8](https://github.com/hurttlocker/o8)** is an open-source control room for running a fleet of coding agents. Claude Code, Codex, Grok Build, OpenCode and fourteen more run in isolated worktrees; the work comes back for review; nothing merges without a recorded decision. Its memory layer, Cortex, keeps project rules and past outcomes with the project instead of with one model vendor. MIT, macOS today, built in public.

Cortex began as **[a standalone library](https://github.com/hurttlocker/cortex)**, import-first and zero-dependency, reachable over MCP. That version still works on its own; the current one lives inside o8.

Smaller tools from the same shop: **[ginsu](https://github.com/hurttlocker/ginsu)** lets one coding agent drive another in a real terminal; **[token-lean](https://github.com/hurttlocker/token-lean)** is the orchestration discipline the fleet runs on.

What I care about: one source of truth, observable state, a human gate that stays useful as delegation grows. Receipts over adjectives.
